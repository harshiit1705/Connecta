# Connecta

Connecta is a full-stack social media platform inspired by modern social networks.  
It focuses on user interaction, content sharing, and real-time engagement.

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT
- Styling: CSS / Tailwind (if applicable)

## Features
- User authentication
- Create, like, and comment on posts
- News feed
- Profile management
- Real-time interactions (planned)

## Status
This project is actively under development.
